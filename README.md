# Bombardiro website

The website for Bombardiro, a football party word game for iPhone and iPad.

- **Live site:** https://bombardiro.app
- **How it's built:** `handoff/SPEC.md`
- **Rules for contributors and agents:** `CLAUDE.md`

The app's word lists are public data. Names of players and clubs appear only as words to describe in the game.
Bombardiro isn't affiliated with or endorsed by any club, player, league or federation.
